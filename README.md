# Laboratorio #2 - HTML5

**Fecha:** [DD/MM/AAAA]

## Contenido del Repositorio

Este repositorio contiene los ejercicios realizados durante el Laboratorio #2 de Desarrollo Web.

En esta práctica se trabajó con HTML5 y CSS, realizando tablas, enlaces, clases, identificadores y diferentes estructuras de una página web.

Los ejercicios realizados incluyen:

- Tabla #1: Informe de gastos de viaje.
- Tabla #2: Tabla con diferentes estilos mediante CSS.
- Ejemplo #3: Uso de etiquetas HTML y selectores CSS.
- Ejemplo #4: Uso de clases, identificadores y enlaces externos.
- Ejemplo #5: Uso de etiquetas semánticas de HTML5.

## Tecnologías Utilizadas

- HTML5
- CSS3
- Visual Studio Code
- WampServer
- GitHub
